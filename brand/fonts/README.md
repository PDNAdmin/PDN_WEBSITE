# Fonts

Put the brand fonts here:

- **Quirkfy** (headings/display): e.g. `Quirkfy-Regular.woff2`, `Quirkfy-Bold.woff2` (or `.otf`/`.ttf`; Claude Code converts them to woff2). Get them from the designer's Drive folder linked on the last page of the brand guide, and confirm the licence allows web embedding.
- **Bricolage Grotesque** (body): free from Google Fonts (OFL). Claude Code downloads the variable font automatically. You don't need to add it here.

If Quirkfy is missing, the site falls back to Bricolage Grotesque 800 for headings and logs a warning.
