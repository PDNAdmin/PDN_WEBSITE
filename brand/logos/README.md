# Logos

Traced from the official brand guide (Zoekraft Studio). Swap in the designer's original vector exports when available, keeping these **exact filenames**.

| File | What |
|---|---|
| `pdn-logo-horizontal-{white,gold,onyx}.svg` | Horizontal lockup: rounded tile with the mark cut out, plus the "Pishon / DIGITAL NETWORK" wordmark. White = default on the dark site. |
| `pdn-icon-{gold,onyx,white}.svg` | App-icon tile only (mark cut out) |
| `pdn-mark-{gold,white,onyx}.svg` | The loop mark alone (filled outline) |
| `pdn-mark-centerline.svg` | **The River**: one stroke path `#pdn-river` through the centre of the mark (viewBox 756×780, stroke ≈ 57). Used for draw-on animations, the scroll river, the 3D tube spine and the Remotion logo resolve. |
| `png/pdn-logo-horizontal-{white,gold}.png` | Raster lockups, transparent, 1200px wide |
| `png/pdn-mark-{white,gold}.png` | Raster mark, transparent; also the shape reference for ChatGPT prompts |
| `png/pdn-favicon-{32,180,512}.png` | Onyx tile + gold mark |

Rules: never tilt, recolour, add transparency to, or put graphics over the logo lockup. The mark *alone* may be animated, rendered in 3D gold, or drawn as a line.
